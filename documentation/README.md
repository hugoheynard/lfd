# Documentation LFC — index

**Cet index fait foi.** Un doc qui n'y figure pas est un doc que personne ne
retrouvera. On le met à jour dans le même commit que le doc qu'on ajoute.

Chaque ligne porte l'**état réel du code**, pas l'intention :

| Marque | Ce que ça veut dire                                         |
| ------ | ----------------------------------------------------------- |
| ✅     | Le doc décrit du code qui tourne.                           |
| 🟡     | Partiellement implémenté — le doc dit **où** est la limite. |
| 📐     | Doc-first : décidé, pas codé. Rien n'existe.                |
| 🔎     | Audit : une **photo datée** du code, pas un plan.           |

> Vérifié contre le code le **2026-08-09**. Les écarts trouvés ce jour-là sont
> consignés dans [`b2b/audit-flux-plateforme-admin.md`](b2b/audit-flux-plateforme-admin.md)

## Où va un nouveau doc

- **Pipelines, build, déploiement, trous de la CI → `ci-cd/`**, TODO compris.
- **Infra, secrets, gestes d'exploitation, sécurité d'accès → `ops/`.**
- Architecture / décision d'un projet → `b2b/`, `pim/`, `suite/`.
- **Ce qui encaisse — entité émettrice, mandat, prélèvement → `comptabilite/`**,
  qui suit le contexte `b2b/accounting/` du code plutôt que le projet.
- **Tout ce qui fabrique un prix ou un total → `pricing/`**, quel que soit le
  contexte qui le porte : la chaîne traverse le référentiel, la boutique et la
  caisse, et la ranger par contexte la coupait en trois.
- **Ce qu'on garde en mémoire au lieu de le relire → `caching-usage/`**, un
  doc par écran : un cache se juge sur ce qu'il périme, et ce qui périme
  dépend de l'écran qui le lit.
- **L'équipe — annuaire, journalisation → `staff/`**, TODO compris.
  | [`droits-et-permissions/plan-outils-agent-droits.md`](droits-et-permissions/plan-outils-agent-droits.md) | ✅ | **Le plan des outils agent de la gestion des droits** (Hugo, 2026-10-15), corrigé après `vitruve`. Bâti le 2026-10-15 ; l'état est dans `outils-agent-droits.md`. |
  | [`droits-et-permissions/plan-droit-lfc-catalog.md`](droits-et-permissions/plan-droit-lfc-catalog.md) | 📐 | **`lfc_catalog` remplace `b2b_catalog`** (Hugo, 2026-10-16) : ressource neuve, droits transférés à l'écran sur aperçu, `b2b_catalog` gardé lisible et ignoré. Corrigé après `vitruve` ; rien n'est bâti. |
- **Droits, rôles, permissions (staff et client) → `droits-et-permissions/`**, TODO compris.
- **Les points ouverts sur la journalisation, tous journaux confondus →
  `journalisation/`** (2026-09-18). Les architectures restent chez leur
  projet ; ce dossier réunit ce qui reste à faire.
- **Identité, Auth0, inscription, connexion, invitations des clients →
  `auth-inscription/`**, TODO compris.
- **Nos lieux — le site, ses rôles, ses couleurs → `sites/`** (2026-10-13) :
  le site appartient au commerce et cinq blocs le lisent ; le ranger sous
  `livraisons/` lui aurait donné un propriétaire qu'il n'a pas.
- TODO, roadmap, inventaire de dette → `todos/`.
- La **racine** ne porte que cet index et le **plan de release courant**.
