**Rassemblé le 2026-09-29** à la demande de Hugo : « on a une grosse pièce qui
nous manque c'est la livraison ». Ce dossier regroupe ce qui était dispersé dans
`b2b/`, `todos/` et `handover-delivery/`.

> code](audit-2026-10-07.md) : 27 documents, ≈ 1 500 affirmations confrontées,
> 23 documents en retard sur le code, corrigés le même jour. Les états
> ci-dessous sont ceux que chaque document déclare **en tête après cette
> relecture** ; les docs d'état décrivent le code, les plans bâtis portent la
> date de leur relecture, et les conceptions dépassées sont marquées 🗄️ avec
> une table « ce qu'elles décrivent → ce qui existe ».
