Comment le PIM est pensé — et comment un simple paramétrage se transforme en collections Shopify. À parcourir section par section, dans l'ordre du rail.

Le référentiel a un back. Les données vivent en base, derrière une API murée par l'annuaire du personnel. Cet encadré annonçait un POC front-only sur localStorage — c'était vrai au début, et ça ne l'est plus depuis longtemps.

Le PIM est la source de vérité du catalogue. On y décrit les catégories, les taux de TVA et les produits ; le système en dérive les collections finales, prêtes à être poussées vers Shopify.
