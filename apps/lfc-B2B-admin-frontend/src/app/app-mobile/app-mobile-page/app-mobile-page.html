Le back-office est l’app mobile : la même adresse, la même session, une mise en page qui change de forme sous 768 px. Rien à installer depuis un magasin d’applications — on l’ajoute à l’écran d’accueil, et elle s’ouvre en plein écran comme une app.

Scannez ce code avec l’appareil photo du téléphone. Vous arriverez sur la page de connexion : connectez-vous une fois, la session tient.

{{ appUrl }}

 Bouton Partager, puis Sur l’écran d’accueil. Menu ⋮, puis Ajouter à l’écran d’accueil. Le rail latéral s’efface. Le bouton en haut à gauche ouvre une grille de tuiles plein écran — une par module, avec ses pastilles. Chaque ligne devient une carte, avec ses actions dans le coin plutôt que dans une colonne qu’il faudrait faire défiler. Les barres d’onglets se replient en accordéon d’icônes : seul l’onglet ouvert garde son libellé. Le téléphone n’ouvre pas de porte de plus. Ce sont vos droits habituels, lus par le backend à chaque appel — l’écran n’a jamais été le mur. Et la coque iOS ? Le dépôt en porte une (Capacitor, en mode distant : elle charge exactement cette adresse, donc elle suit les déploiements sans être reconstruite). Elle n’est installée sur aucun téléphone à ce jour, et elle n’apporte rien de plus que l’écran d’accueil tant qu’on ne veut ni caméra native ni notifications système.
